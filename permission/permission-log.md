# Linux 파일 및 디렉터리 권한 관리 실습

## 1. 실습 목적

Linux 환경에서 파일과 디렉터리의 접근 권한을 확인하고 `chmod` 명령어를 이용하여 권한을 변경하는 실습을 진행하였다.

파일과 디렉터리의 권한 설정 방식 및 숫자형 권한 표기법을 이해하는 것을 목표로 하였다.

## 2. 실습 환경

| 항목 | 내용 |
|---|---|
| 운영체제 | Ubuntu 26.04.1 LTS |
| 실행 환경 | WSL2 |
| 터미널 | Ubuntu Bash |
| 사용 명령어 | chmod, ls |

## 3. 실습 대상 생성

실습을 위해 파일과 디렉터리를 생성하였다.

```bash
mkdir -p ~/codyssey-practice/permission-test
cd ~/codyssey-practice/permission-test
touch test.txt
mkdir test-dir
```

## 4. 변경 전 권한 확인

다음 명령어로 파일과 디렉터리의 기존 권한을 확인하였다.

```bash
ls -l
```

변경 전 권한:

| 대상 | 권한 | 숫자 표기 |
|---|---|---|
| test.txt | -rw-r--r-- | 644 |
| test-dir | drwxr-xr-x | 755 |

- 파일 권한 644: 소유자는 읽기와 쓰기, 그룹과 기타 사용자는 읽기 가능
- 디렉터리 권한 755: 소유자는 읽기, 쓰기, 실행 가능하며 그룹과 기타 사용자는 읽기와 실행 가능

## 5. 권한 변경

`chmod` 명령어를 사용하여 파일과 디렉터리의 권한을 변경하였다.

```bash
chmod 600 test.txt
chmod 700 test-dir
```

### 권한 변경 결과

| 대상 | 변경 전 | 변경 후 |
|---|---|---|
| test.txt | 644 | 600 |
| test-dir | 755 | 700 |

- 600: 소유자만 읽기와 쓰기 가능
- 700: 소유자만 읽기, 쓰기, 실행 가능

## 6. 변경 후 권한 확인

다음 명령어를 사용하여 변경된 권한을 확인하였다.

```bash
ls -l test.txt
ls -ld test-dir
```

변경 후 결과:

```text
test.txt  -rw-------
test-dir  drwx------
```

권한이 지정한 값으로 정상적으로 변경된 것을 확인하였다.

## 7. 실습 결과

- Linux 파일 및 디렉터리 권한 확인
- `chmod` 명령어를 이용한 권한 변경
- 숫자형 권한 표기법 644, 755, 600, 700 이해
- 변경 전후 권한 비교 및 확인 완료
